Claude 的預覽視窗會擋掉 Google 的登入畫面。要真的登入，請用你自己的網址開啟這個 App。

怎麼領這串代碼

  1. 用電腦打開 console.cloud.google.com，登入同一個 Google 帳號
  2. 左上角專案選單 → 新增專案，名稱隨便打，按建立
  3. API 和服務 → 程式庫，搜尋 Google Calendar API，按啟用
  4. OAuth 同意畫面：使用者類型選外部，填名稱和你的信箱，一路按儲存；最後在測試使用者把要用的 Gmail 加進去
  5. 憑證 → 建立憑證 → OAuth 用戶端 ID，類型選網頁應用程式
  6. 「已授權的 JavaScript 來源」貼上 你的網址，按建立
  7. 複製跳出來的那串代碼，貼進上面的框

匯入行事曆檔案

不用登入、不用連接器。Google 行事曆給每本日曆一個私人 iCal 網址，把那份檔案餵進來， 這個 App 就會用你真正的行程運作。

  1. 在電腦版 Google 行事曆，左側把滑鼠移到日曆名稱 → ⋮ → 設定和共用
  2. 捲到最下面，複製「日曆的私人網址 (iCal 格式)」——結尾是 basic.ics
  3. 把那個網址貼進瀏覽器打開，全選內容複製，貼到下面的框；或把下載到的 .ics 檔案選進來
選擇 .ics 檔案 檔案只在這台裝置上解析，不會被上傳
這是唯讀快照
匯入的行程不會同步，之後改了要重新匯入一次；新增的行程也不會寫回 Google。要雙向同步，還是得走連接器或自架授權。
